# BioPrint final report

Start with **bioprint-report.pdf**: six A4 pages prepared for hackathon judges with academic and industry expertise. It follows the requested introduction, final methodology, experimental setup, results and conclusion structure. Figures are vector graphics generated by LaTeX/PGFPlots.

This is the final six-page report. The initial PDF and source are preserved under `versions/v1/`. Revision 2 defines notation and abbreviations, explains each main dataset and baseline-to-candidate method, adds device fingerprinting, reports typing-only diagnostics, and analyzes the paired pointer tradeoff statistically. Additional studies explain architectural choices rather than appearing only as a catalog of scores.

## Files

- `bioprint-report.tex`: editable report source.
- `complete-results.csv`: full companion ledger of dataset variants, general-typing models, original policy splits, pointer integration variants, threshold counterfactuals and unavailable studies. Repeated controls are intentionally retained; rows are not independent experiments.
- `evidence-manifest.json`: hashes of the consumed reports and original dataset-report hashes. Source paths are relative to the repository root.
- `prepare.py`: regenerates the principal tables, plot data and ledger from saved results. It does not rerun models, read the live account database or alter a server.
- `analyze_comparisons.py` and `paired-comparison-analysis.json`: reproducible account-level sign-flip comparison and synthetic typing diagnostics. Interpretation is conditional on the artificial mapping, with repeated scenarios clustered by account.
- `typing-demo-results.json`: actual API demo outcomes, including typing scores, login decisions and session checks. These are outcome-selected illustrations, not an accuracy estimate.
- `build.sh`: prepares the evidence and runs PDFLaTeX twice.

From the repository root:

```bash
bash reports/2026-09-20/bioprint-report-draft/build.sh
```

The preparation script uses the repository's `bigidea` environment. LaTeX requires the installed `pdflatex`, PGFPlots, TikZ, booktabs, tabularx, tcolorbox and Latin Modern packages. No external image downloads are needed.

## Reading the evidence

The six-page report covers every experiment family and the principal comparisons; the ledger preserves the individual variants that would be unreadable if squeezed into six pages. Percentages in CSV are numeric percentage units (e.g., 10 means 10%), with blank cells for unavailable metrics. General-typing rows use the rounded rates from their source tables; source reports preserve detailed counts.

The final methodology reflects `experiment/typing-pointer` at `f409a4d`. The 10.00% FAR / 31.67% FRR result belongs to the earlier paired synthetic pointer evaluation, before the live phone bot-rule correction and mobile threshold relaxation. It is not measured accuracy for the latest live policy. No app-wide EER is invented.

External background sources are linked in the PDF: NIST SP 800-63B-4, BioCatch's official product overview, and the CMU benchmark page. Experimental numbers come from local evidence, not vendor claims. No private account names, credentials or live movement recordings are included.

## One-command typing-model demo

```bash
bash experiments/typing_demo/run.sh
```

This creates temporary synthetic enrollments, fits the actual compatible typing model and calls the login API, then opens a browser report. Add `--no-open` for headless use. No listener is started and the live account database is untouched. The public benchmark password is `.tie5Roanl`. The first four examples are typing-classifier outcomes; a fifth owner-like attack shows an actual login false accept. The false-accept classifier example is correctly intercepted by the stricter direct-login policy.
