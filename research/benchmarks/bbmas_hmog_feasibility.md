# BB-MAS and HMOG paired-data feasibility

Metadata-only audit, 2026-09-20. No measurement archive, member, or reserved observation was downloaded or decoded. Existing dataset notes were checked first; their brief HMOG “open” description does not establish unrestricted licensing or bounded acquisition.

## SU-AIS BB-MAS

The publisher calls this **Syracuse University and Assured Information Security**, not SMU. The [original paper](https://arxiv.org/html/1912.02736) describes 117 participants, desktop keyboard/mouse, tablet and phone typing/touch, and accelerometer/gyroscope recordings. Timestamped, same-person modalities offer genuine fusion opportunities. Different device tasks are sequential; they must not be presented as simultaneous recording windows. Collection is one approximately 2–2.5-hour visit per participant; repeated sentences are not independent longitudinal visits. The paper warns that desktop mouse sampling problems produced small mouse files.

The [official DOI](https://doi.org/10.21227/rpaz-0h66) resolves to IEEE DataPort. The paper explicitly requires a free IEEE account for downloading. This audit did not authenticate or request access. DataPort was blocked by the browsing tool; [DataCite metadata](https://api.datacite.org/dois/10.21227/rpaz-0h66) confirms CC BY 4.0 but contains empty size and format arrays. Anonymous selective download and an exact archive size remain unverified.

A conditional desktop subset is four documented files per participant: `<ID>/<ID>_Desktop_Keyboard.csv`, `<ID>/<ID>_Mouse_Move.csv`, `<ID>/<ID>_Mouse_Button.csv`, and `<ID>/<ID>_Mouse_Wheel.csv`, with IDs 1–117. Before acquisition, obtain official member sizes, freeze identity partitions and temporal enrollment/probe rules, and ensure selected compressed and extracted data fit the 500 MB limit. Do not claim this subset is currently anonymously downloadable or that desktop motion density is adequate.

## HMOG

The [official repository](https://github.com/hmog-dataset/hmog) describes 100 volunteers, each expected to complete 24 sessions: eight reading, eight writing, and eight map-navigation sessions, sitting or walking. Sessions last 5–15 minutes. Touch, keypress, and inertial signals are recorded together, making writing sessions a promising mobile typing/touch/motion benchmark with repeated sessions. It does not supply desktop pointer behavior, scrambled-keypad cognition, or bot/replay labels. Session count is a collection expectation, not a verified completeness guarantee for every identity.

The publisher links a single [Box archive](https://wm1693.box.com/s/jkjodaw2scunua7b7qaxt3ker5w9lwt7). Its public landing returned HTTP 200 and identifies `hmog_dataset.zip`, file ID `770692248712`, version `822468323512`, **6,132,356,276 bytes**, SHA-1 `ff7970cdd4a16bc918b5af941515363f806f9b1f`. Full acquisition exceeds both the 500 MB dataset allowance and the 5 GB combined allowance. The official GitHub tree contains documentation only. Neither individual downloadable members nor a public archive-range route was verified within this bounded audit.

A follow-up tested the landing's `authenticated_download_url`, `https://public.boxcloud.com/api/2.0/files/770692248712/content`, anonymously with `Range: bytes=-65536`. The request sent no credentials, cookies, or shared access tokens and allowed at most 65,536 response bytes, conditional on HTTP 206 plus `Content-Range`. It returned **HTTP 400, Content-Length 0, no Content-Range**; zero body bytes were read. `hmog_range_receipt.json` records the exact request and response metadata. This failed public range check does not prove all possible selective access is impossible, but it does not establish a usable acquisition path. No ZIP tail or measurement member was retrieved.

A second, bounded check used the ordinary public shared-file endpoint: `https://wm1693.app.box.com/index.php?rm=box_download_shared_file&shared_name=jkjodaw2scunua7b7qaxt3ker5w9lwt7&file_id=f_770692248712`. It returned **302 to a signed public Boxcloud download URL**, demonstrating that the anonymous shared download flow resolves without account login. Following that redirect with the same `Range: bytes=-65536` returned **400, Content-Length 0, no Content-Range**. Zero body bytes were read, and the attempt stopped. The full request/redirect/status receipt is `hmog_shared_download_receipt.json`. Thus public download resolution works; bounded range delivery remains unverified in this environment. Do not reinterpret either HTTP 400 as evidence that HMOG requires authentication or cannot be publicly downloaded.

**Explicit-range follow-up succeeded and supersedes the range-access blocker above.** A fresh anonymous shared-file redirect with `Range: bytes=6132290740-6132356275` returned HTTP 206 with exactly `Content-Range: bytes 6132290740-6132356275/6132356276`, and 65,536 bytes were saved. Only ZIP structural metadata was parsed; no compressed measurement member was decoded. The ZIP64 central directory starts at byte 6,132,348,588 and spans 7,590 bytes, entirely within that tail. It lists 100 subject ZIPs, a directory, and `public_dataset/data_description.pdf`. Receipts and parsed member names, sizes, methods, and local-header offsets are in `hmog_explicit_range_receipt.json` and `hmog_zip_member_metadata.json`.

Selective subject acquisition is now technically supported. An exact metadata-determined candidate is the first five sorted subject IDs `100669`, `151985`, `171538`, `180679`, `186676`: their nested ZIPs total **314,280,530 bytes** after outer decompression. Each subject ZIP is itself DEFLATE-compressed in the outer archive, so accessing inner session metadata requires acquiring/decompressing that selected outer member; direct arbitrary inner-session ranges are not possible from outer offsets alone. Stream outer compressed bytes into bounded nested ZIP files rather than storing both copies. A larger size-selected 12-subject candidate totals 427,718,950 bytes, but selecting the smallest archives could bias session completeness and should not be adopted silently. Neither candidate has been acquired or selected for evaluation. Subject subsets, train/dev/test roles, inner session schema/completeness checks, and bounds on retained extracted data must be preregistered before measurements are inspected. The 105,821-byte description PDF is a separately addressable non-measurement member.

The official terms restrict use to noncommercial education/research and prohibit redistribution without permission; this is not a permissive open-data license. Any subsequent research acquisition must remain within those terms. No login or account credentials were needed for the successful metadata request.

## Decision and audit artifacts

HMOG offers stronger repeated-session mobile evidence and a verified anonymous range route supporting bounded subject-level acquisition; BB-MAS offers broader devices and desktop modalities with weaker longitudinal evidence and unresolved access. Keep both as acquisition candidates, not completed evaluation coverage. Metadata snapshots are in `datasets/joint_feasibility_metadata/`: official HMOG README and GitHub tree, BB-MAS DataCite response, access URLs, public HMOG Box landing, range receipts, ZIP tail, and central-directory metadata. No account authentication, agreement submission, or measurement-member decoding occurred.

## Acquisition-only follow-through

After the metadata audit, a separate frozen plan selected the 12 smallest subject ZIPs (explicit size/completeness bias), then assigned identity roles using ascending SHA256(`20260920:<ID>`): four fit, two selection, two calibration, four dev. The next four size-ranked IDs are explicit sealed test; the remaining 84 are unused/sealed. This later plan supersedes the illustrative five-subject option above.

All 12 archives were acquired successfully via exact 206 byte ranges and streamed outer DEFLATE, retaining **427,718,950 raw nested-ZIP bytes**. Post-acquisition SHA256 revalidation passed all 12; all CRC32 and declared sizes matched; no partial files remained and no sealed-test/unused archives were acquired. HMOG plus discovery metadata occupied approximately **428.53 MB**, below 500 MB. Two generated-data tests passed. The public publisher SHA1 remains declared, not whole-archive-verified.

The files are in `datasets/hmog/raw/`; frozen identity roles, source receipts, script hashes, inner directory metadata, and verification records are in `datasets/hmog/`. **All inner measurement members remain sealed, including fit/dev identities.** A separate session enrollment/support/probe plan must precede any measurement decoding. No training, evaluation, or quality-improvement claim follows from this acquisition. Discovery/index planning preceded the recorded preregistration timestamp; exact planning duration was not instrumented, while per-subject transfer durations are recorded in receipts.
