What is BioPrint measuring?

Only timing: how long each physical key is held down, the gaps between keys, and how the pointer travels to the button. The characters you type are used solely to line up the comparison.

Nothing here replaces your password — it is a second, silent check that the person typing it is you. There is no OTP and no second device: the decision is made from behaviour alone, in a millisecond or two.
